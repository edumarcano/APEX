# Corresponding source materials

These pinned source and license materials are copied into each all-extras backend bundle where runtime wheels omit required upstream materials.

- `espeak-ng-1.52.0.tar.gz` is the eSpeak NG source tree at upstream commit `4870adfa25b1a32b4361592f1be8a40337c58d6c` (tag `1.52.0`). The `espeakng-loader` 0.2.4 build workflow at commit `146599e29be31bf17d99f0bcb7dbb2f92aef3d95` explicitly clones that tag. Its `build.sh` runs CMake configure, build, and install commands to produce the shared library and data used by the loader wheel. The source archive contains upstream license files and build files.
- `espeakng-loader-0.2.4-source.tar.gz` is the loader wrapper source at upstream commit `0ddc87adf77e5850d7eeb542ac8a87d421b64daa`, with an MIT license naming `thewh1teagle` and copyright year 2025. This commit is a direct child of the exact 0.2.4 build commit above. The installed wheel's `espeakng_loader/__init__.py` matches this source after normalizing CRLF to LF; the collector verifies that match before staging the MIT grant. The wheel itself omits the license file. `espeakng-loader-source.json` records the archive hash and both revisions.
- `phonemizer-fork-3.3.2.tar.gz` is the source distribution pinned by `uv.lock`; its SHA-256 is checked against the lockfile before staging.
- `pygame_ce-2.5.7.tar.gz` is the exact source distribution pinned by `uv.lock`. The notice collector reads its upstream license files only after validating the sdist hash. It is copied into the bundle as pygame-ce package source; `docs/LGPL.txt` and `docs/licenses/` preserve pygame-ce terms and the native component notices carried with this release. The Windows wheel build helper pins SDL2 2.32.10, SDL2_image 2.8.8-pgce, SDL2_ttf 2.24.0, and SDL2_mixer 2.8.1. PE version strings from the locked wheel identify libxmp 4.6.1 and WavPack 5.6.0; their separate original license files and source revisions are pinned in `libxmp-source.json` and `wavpack-source.json`. The current inventory has not independently matched every other bundled codec DLL to an exact upstream build revision; their original license texts from the exact pygame-ce sdist are included, but per-DLL source provenance for those files remains unverified.
- FastMCP Slim 3.4.4, Loguru 0.7.3, and FlatBuffers 25.12.19 omit license texts from their locked wheels (and their sdists omit the corresponding file where applicable). Their original upstream LICENSE files are pinned by exact source revision, locked wheel hash, and license-text hash in the respective `*-source.json` manifests.
- `pypiwin32` 223 is a metadata-only compatibility package: its installed distribution has no files outside `.dist-info` and contributes no importable runtime code, so it is omitted from the frozen-runtime notice inventory.
- `flatbuffers` 25.12.19 has no source distribution in `uv.lock` and its wheel omits a license file. `flatbuffers-source.json` pins the original upstream license text to the exact source commit and locked wheel hash.

The build helper verifies the source archive hashes and upstream revision mapping before copying them into `licenses/source-material/`. It also compares the installed loader wrapper against the archived MIT-licensed source before copying that grant into `licenses/espeakng-loader-0.2.4/`. It verifies version markers for the separately mapped libxmp and WavPack DLLs before staging their licenses, and fails closed if an archive is absent, differs from the recorded source, or does not match the installed wheel. Other pygame-bundled DLLs have their release-carried license texts included, while exact DLL-to-source revision mapping remains an evidence gap.
