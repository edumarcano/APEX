# TypeScript and JavaScript reference

Applicability evidence: JavaScript/TypeScript sources or an approved language
decision, not merely a proposal in a product specification.

Inspect actual package scripts, lockfiles, compiler configuration, module/runtime
boundaries, and component working directories. Ask which public contracts, async
failure paths, or input boundaries change and which checks exercise them.

Do not infer a package manager, framework, browser, monorepo, or test runner.
TypeScript does not imply Next.js or a deployed web application. Do not install
dependencies during passive discovery or claim a configured script passed.
